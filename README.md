# Auto Gladiators 2

Mobile web playtest, version 0.1.0.

Eight champions, one survivor. Tap cards to buy, hold for details, then press Ready to fight seven bots. Progress and saves stay in your browser.

Built from the owner's AutoGladiators assets and game data, with a new interface and experimental turbo rules. This repository contains the static playable only; it does not contain the Unity project, internal documentation, analytics exports or development workbooks.

Game assets remain the property of their respective rights holders. Font license notices are included.
